# Easy Scanlate Documentation

Welcome to the official documentation for Easy Scanlate, a powerful tool designed to streamline the process of translating and typesetting comics and manhwa. This guide serves as a central hub for installation instructions, tutorials, and detailed feature breakdowns.

Whether you're a new user or an experienced one, these links will guide you to the information you need.

Dive deep into the application's features with the comprehensive user manual. Learn how to leverage the full power of the tool to optimize your workflow.

*   **[Main Application Window](/user-manual/main-application-window/):** Toolbar, pages, and side panel tour.
*   **[Project Management](/user-manual/project-management/):** Saving (`.mmtl` = one file) and versions with profiles.

*   **[Settings](/user-manual/settings/):** Everyday prefs, detection tuning, translation, shortcuts.
