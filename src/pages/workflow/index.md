# Workflows & Tutorials

This section provides hands-on guides for using Easy Scanlate effectively. Whether you're just getting started or looking for optimized workflows for specific project types, you'll find practical, step-by-step instructions here.

## Available Guides

### For New Users

**[Your First Project](/workflow/your-first-project/)**

A complete walkthrough from installation to final export. This tutorial guides you through creating your first project, running OCR, editing text, and exporting translated images. Perfect for getting familiar with the entire workflow.

**[Common Workflows](/workflow/common-workflows/)**

*   **Multi-Chapter Management** - Organizing and managing larger projects
*   **Quick OCR Workflow** - Fast extraction without translation
*   **Collaboration Workflow** - Working with external translators

## Quick Start Tips

*   **Start Small**: Try your first project with just 2-3 images to learn the interface
*   **Save Often**: Use `Ctrl+S` frequently, especially before running batch operations
*   **Use Manual OCR**: Don't forget you can manually select missed text areas after batch OCR
*   **Experiment with Profiles**: Create multiple profiles to compare translation versions

Once you've completed "Your First Project", you'll have the foundation to tackle any of the specialized workflows.
