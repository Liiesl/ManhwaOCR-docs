# User Manual: Easy Scanlate

Welcome to the official user manual for the Easy Scanlate. This guide provides detailed, step-by-step instructions for every feature available in the application.

This manual is organized into the following sections:

1.  **[The Main Application Window](/user-manual/main-application-window/):** A detailed overview of the primary workspace.
2.  **[Project Management](/user-manual/project-management/):** Learn how to manage text versions using profiles.
3.  **[Image Manipulation](/user-manual/image-manipulation/):** Instructions for stitching and splitting images.
4.  **[OCR Processing](/user-manual/ocr-processing/):** Covers both automated Batch OCR and precise Manual OCR.
5.  **[Text Editing & Management](/user-manual/text-editing/):** A guide to using the Results Widget and Find/Replace tool.
6.  **[Text Box Styling](/user-manual/text-box-styling/):** Detailed options for customizing the appearance of text.
7.  **[AI Translation](/user-manual/ai-translation/):** How to use the integrated Gemini Translation feature.
8.  **[Import & Export](/user-manual/import-export/):** Instructions for importing and exporting project data.
9.  **[Settings](/user-manual/settings/):** A complete reference for all application settings.

If you are new to the tool, please start with the **[Getting Started](/getting-started/)** guide first.
