# Custom Fonts

Easy Scanlate comes with comic-ready fonts built in (Anime Ace + Augie), and it also lists the fonts already on your computer. In most cases there's nothing to install — just pick and go.

---

## Using fonts (no setup needed)

1.  Click a text box on the page to select it.
2.  In the **Style panel**, open the **Font Family** dropdown.
3.  Pick anything you like — changes apply instantly.

If a font has variants, a **Font Style** dropdown appears (Regular / Bold / Italic...). The **B / I** buttons are quick toggles for emphasis and look best when the font has real bold/italic versions.

### The default

**Default** uses Anime Ace, a comic/manga-style font that reads well small and sits nicely in bubbles. If you never touch fonts, you'll still look good.

---

## Want more fonts? Just install them normally

There's no special fonts folder to hunt for. Install fonts the usual way for your computer (double-click a `.ttf` / `.otf` → Install), restart Easy Scanlate, and they'll show up in the list.

| Format | Extension | Notes |
|--------|-----------|-------|
| TrueType | `.ttf` | Most common, works great |
| OpenType | `.otf` | Works great too |

Both work the same here.

### Good places to look

*   **Blambot** (blambot.com) — comic fonts (free for indie projects, check license)
*   **Google Fonts** — search "comic" or "display"
*   **FontSquirrel** — free commercial-use options

Always check the license before publishing with a font.

---

## Tips for nice-looking text

*   **Auto size** (on by default) fits words to the box — leave it on unless you have a reason.
*   **Outline:** 1–3px white on dark words (or dark on light words) helps on busy art.
*   **Bold** for shouting / emphasis, *Italic* for thoughts or stress.
*   **Center** for bubbles, **Left** for narration boxes.
*   **Save combos as presets:** Style one box perfectly → `+` in Presets → name it ("Main Dialogue", "Narration") → click to reuse everywhere.

## If a font misbehaves

### I installed a font but don't see it

Close and reopen Easy Scanlate so it re-reads your system fonts.

### Weird boxes / missing letters

That font doesn't cover your language's characters. Try one with proper support for Korean / Japanese / Chinese if that's what you're setting.

### Blurry or doesn't fit

*   Try a slightly bigger size or turn **Auto size** back on.
*   Add a touch of outline for definition.
*   Drag the box bigger — cramped boxes make any font sad.

### Bold / Italic buttons do nothing

That font has no bold/italic version. Pick its Style variant from the dropdown if there is one, or try another font.

### The app chokes on a font

Remove the newest font you added, restart, and re-add others one by one to find the culprit. Re-download it from a trusted source.
